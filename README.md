# CyberRoute

## Description

My first standalone project through Boot.dev!

In this project, I am building a route generator for the game Cyberpunk 2077. This app generates a character profile for players when they run out of ideas for how to play the game.

Features include:
- Generating gender, starting lifepath, and build type
- In-depth build paths and attribute allocations
- Suggested dialogue choices and story decisions to get the most out of the experience

## Prerequisites

- [Python](https://www.python.org/) (v3.10+)
- [Git](https://git-scm.com/)

## Installation & Running

1. Clone the repository:
   ```bash
   git clone https://github.com/Peyton03/personal-project-CyberRoute-.git

2. Navigate into the directory:
    cd personal-project-CyberRoute-

3. Install dependencies:
    pip install -r requirements.txt

4. Run the application:
    python3 main.py
